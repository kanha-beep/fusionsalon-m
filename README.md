# Fusion Unisex Salon

Full-stack salon website with a React frontend and Express backend contact form.

## Run locally

1. Install dependencies in the root, client, and server folders.
2. Start both apps:

```bash
npm run dev
```

Frontend default: `http://localhost:5173`

Backend default: `http://localhost:5000`

## Update business details

Edit shared content in `client/src/data/siteContent.js`:

- phone number
- WhatsApp number
- address
- timings
- service text
"# fusionsalon-m"
